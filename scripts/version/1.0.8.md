## What's Changed

CI fix only, no app-facing changes: v1.0.7 built and signed successfully
(the earlier code-signing and Flutter-version fixes both held), but the
upload to App Store Connect was rejected — "This app was built with the
iOS 18.5 SDK. All iOS and iPadOS apps must be built with the iOS 26 SDK or
later." `macos-15` runners only carry Xcode 16.4. Switched both iOS
workflows to `macos-latest` to pick up a current Xcode/SDK.

- Updated pubspec version to 1.0.8+59
- .github/workflows/ios-release.yml and ios-test.yml: runs-on macos-latest
