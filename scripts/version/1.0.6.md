# Version 1.0.6

- Date: 2026-08-20
- Build: 57

## What's Changed

CI fix only, no app-facing changes: archive unsigned and let `-exportArchive`
apply manual signing, instead of forcing `CODE_SIGN_STYLE=Manual` +
`PROVISIONING_PROFILE(_SPECIFIER)` via xcargs during the archive step. That
project-wide xcargs override was being inherited by the Swift Package
Manager product targets several plugins now resolve through (device_info_plus,
camera_avfoundation, local_auth_darwin, and others), which don't support
provisioning profiles and made the Xcode 16.4 archive fail outright.

## Release updates included

- Updated pubspec version to 1.0.6+57
- ios/fastlane/Fastfile: gym now archives with CODE_SIGNING_ALLOWED=NO /
  CODE_SIGNING_REQUIRED=NO; manual signing is applied only at export via
  the existing export_options provisioningProfiles mapping
