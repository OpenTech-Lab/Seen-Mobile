# Version 1.0.7

- Date: 2026-08-20
- Build: 58

## What's Changed

CI fix only, no app-facing changes: pin the CI Flutter version instead of
floating on `channel: stable`. That let CI silently pick up a newer
Flutter/Dart than what's verified working locally, and the newer toolchain
failed to compile `lib/theme/spot_theme.dart` (`CupertinoPageTransitionsBuilder`
came back as "Method not found" during the kernel snapshot step). Pinned to
3.41.9, the version already verified to build and pass the full test suite.

## Release updates included

- Updated pubspec version to 1.0.7+58
- .github/workflows/ios-release.yml and ios-test.yml: flutter-action now
  pins flutter-version: 3.41.9 instead of channel: stable
